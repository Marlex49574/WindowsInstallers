This repository is organized with a dedicated folder for each program. Each program's folder will contain its installer scripts and related files.

## Adding a New Program

To add a new program:
1. Create a new folder with the program name
2. Add installer scripts (PowerShell files) inside that folder
3. Include any necessary configuration or documentation files

## Installer Guidelines

Each program folder should contain:
- PowerShell installer script(s) for offline/online installation
- README (optional) with specific installation instructions
- Any required configuration files
